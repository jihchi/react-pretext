# react-pretext

React component for [`@chenglou/pretext`](https://github.com/chenglou/pretext) -- fast, accurate multiline text measurement without DOM reflow.

## Getting Started

```sh
npm add react-pretext
```

## Development

- Install dependencies:

```bash
vp install
```

- Run the unit tests:

```bash
vp test
```

- Build the library:

```bash
vp pack
```
